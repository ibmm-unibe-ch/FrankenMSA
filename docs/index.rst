FrankenMSA
==========

FrankenMSA is a library for manipulating, filtering, combining, visualizing,
and augmenting protein multiple sequence alignments while keeping the core data
model simple: a pandas DataFrame with a ``sequence`` column.

The documentation is organized into installation guidance, an API reference,
and user-facing sections for tutorials and the GUI.
